# McMusic 改进功能需求（Final）

## 1. Bug 修复
- 「允许的音乐软件」设置点「完成」直接回游戏 → 应返回上一级设置界面。

## 2. 允许的音乐软件 — 动态检测与分类
- 动态读取系统已安装媒体软件，只显示已安装项（未安装不列选项）。
- macOS 扩展来源：Edge、Firefox、QQ Music、QuickTime Player 等。
- 分类按类型：音乐软件 / 浏览器 / 播放器。

## 3. 设置界面改造（仿游戏规则 UI）
- 复刻《我的世界》「游戏规则」面板：完成 / 取消按钮、搜索框、开关。
- 分类：按类型（音乐软件 / 浏览器 / 播放器）。
- 授权逻辑：
  - 未授权 → 默认关闭 + 悬浮窗提示「需要权限」
  - 已授权 → 自由开关
  - 被拒绝 → 变灰（不可操作）
  - 「完成」旁入口 → macOS 设置 → 隐私与安全性 → 自动化

## 4. Toast 列位置修复
- 切歌后当前播放 Toast 的「列」定位不刷新、残留固定 → 随切歌正确重排、不残留。

## 5. 弹窗显示触发（互斥三选一按钮）
- 单一按钮，三项互斥（同时仅一个生效），对应不同需求：
  - A. 音乐信息改变后显示
  - B. 暂停后点击播放（恢复）时显示
  - C. 上一首倒数 3/2/1 秒播完切下一首时显示

## 6. 暂停恢复弹窗动画
- 暂停后恢复播放的弹窗动画改为 0 秒出现（瞬显），模仿原版。

## 7. 曲目文字显示
- 歌名、作者各占 30 字，超出省略号截断，两者独立互不打架。
- 无作者：不显示作者，删除连接符（如「 - 」）。
